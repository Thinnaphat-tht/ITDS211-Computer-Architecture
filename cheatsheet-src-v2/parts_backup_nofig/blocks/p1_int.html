★ Interrupt flow
  1. Save register / PC / status ปัจจุบัน
  2. เปิด Interrupt Vector table หา ISR address (เช่น เบอร์ 003 = คีย์บอร์ด)
  3. ใส่ address นั้นใน PC → รัน ISR
  4. Restore ค่าที่ save ไว้ → กลับไปทำงานเดิม
  • Sequential: เกิด → ทำ → กลับ → เกิดอีก → ทำ → กลับ
  • Nested: Y ซ้อนเข้ามาระหว่าง X → save X, ทำ Y, คืนค่า X, ทำ X ต่อ
  • ซ้อนได้กี่ชั้น = จำนวน register ที่เก็บค่าได้
