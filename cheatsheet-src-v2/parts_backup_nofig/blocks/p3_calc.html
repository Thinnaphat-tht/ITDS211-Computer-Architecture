Ch04คำนวณบิต Tag/Index/Offsetเสริม

Offset = log₂(bytes ต่อ block)
Index = log₂(จำนวน block)
Tag = บิต address − Index − Offset
ตย. 4 KB direct-mapped, 16 B/block, address 32 บิต
  • 4096 / 16 = 256 block
  • Index 8 · Offset 4 · Tag 32 − 8 − 4 = 20
  • ถ้า 2-way: sets = 128 → Index 7 · Tag 21
  • Hit ratio = hits / accesses
  • Miss ratio = 1 − hit ratio
  • Block ใหญ่ขึ้น: miss rate ลด (spatial locality)
  • แต่ cache เท่าเดิมมี block น้อยลง แย่งกันมากขึ้น miss penalty สูงขึ้น → ใหญ่ ≠ ดีเสมอ
