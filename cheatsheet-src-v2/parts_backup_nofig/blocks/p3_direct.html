Cache index = (Block address) mod (#Blocks)
→ ใช้ บิตล่าง เป็น index
Address = [ Tag | Index | Offset ]
  • เช็ก hit: ดู Index → เทียบ Tag → ดู Valid (V) = Y
  • เริ่มต้น cache ว่าง (V = N)
  • ครั้งแรกของทุก address = Miss แน่นอน
  • ข้อเสีย: หลาย address ชิงช่อง index เดียวกัน
