Ch06Storage · HDD · RAID★ เน้น HDD

  • เขียน: กระแสไฟเข้าหัวเขียน → สนามแม่เหล็ก → จัดทิศอนุภาคบนจาน (ซ้าย/ขวา = 0/1)
  • อ่าน: ขดลวดเหนี่ยวนำสัญญาณ
  • Platter หลายชั้น · 1 หัวต่อ 1 ผิว
  • Track = วงแหวน 1 วง
  • Sector = ส่วนย่อยของ track ⚠ ไม่ใช่กลุ่มของ track
  • ปัจจุบันใช้ Multi-zone recording (sector ขนาดใกล้เคียงกัน)
  • SSD เร็วกว่า ประหยัดไฟกว่า แต่แพงกว่า HDD
  • DVD จุมากกว่า CD (sector เล็กกว่า density สูงกว่า)
  • Tape ถูกสุด
RAIDลักษณะ
0Striping กระจายเป็นชิ้นเล็กลงหลายดิสก์ (ไม่มีสำรอง)
1Mirror เขียนซ้ำ 2 ดิสก์ เปลืองแต่ปลอดภัย
2เก็บ parity bit / ECC กู้ข้อมูลได้
3ระดับ byte + parity ดิสก์เดียว
4ระดับ block + parity disk แยก → คอขวด
5block + parity หมุนเวียนทุกดิสก์ (แก้คอขวด RAID 4)
6เหมือน 5 แต่ parity 2 ชุด
