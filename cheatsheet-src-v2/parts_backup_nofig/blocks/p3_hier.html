Ch04Memory Hierarchy · SRAM/DRAM★ จำรูปพีระมิด

  • บนพีระมิด = เร็ว · แพง · จุน้อย
  • ล่างพีระมิด = ช้า · ถูก · จุมาก
  • เรียง: Register → Cache → Main memory
  • → (นอกบอร์ด) Magnetic disk, CD, DVD, Blu-ray → Magnetic tape
  • Magnetic tape = ถูกสุด จุมากสุด (offline) ★ อาจารย์ถาม
ความเร็วราคาหมายเหตุ
SRAMเร็ว 0.5–2.5 ns
(~100× DRAM)		แพงtransistor ไม่กี่ตัว ใช้เป็น Cache
DRAMช้ากว่า 50–70 nsถูกเก็บเป็นประจุใน capacitor ต้องชาร์จ (refresh)
Disk5–20 msถูกมากเขียนด้วย magnetic
  • RAM = ชั่วคราว (ไฟดับหาย)
  • ROM = ถาวร (ปิดไฟแล้วอยู่)
  • Cache คั่นกลาง CPU ↔ Main memory เก็บข้อมูลที่ใช้บ่อย/ซ้ำ
  • L1 อยู่ใน CPU · L2/L3 อยู่นอก CPU
  • Hit = เจอใน cache
  • Miss = ไม่เจอ → ดึงจาก main memory มาใส่ cache แล้วส่ง CPU
