Ch03Assembly (RISC-V)★ ช้อยส์ ไม่ต้องเขียนโค้ด

  • ต้องรู้แค่ว่าคำสั่งทำอะไร ไม่เจาะจงตระกูล
  • ADD A,B,C = B + C เก็บใน A
  • LOAD = Memory → Register
  • STORE = Register → Memory
  • ADDI = register + ค่าคงที่ (immediate)
  • addi x22,x22,4 = x22 ← x22 + 4
