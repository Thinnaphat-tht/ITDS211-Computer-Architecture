Ch07Pipeline · Hazard★ ถามชนิด/วิธีแก้

  • Pipeline = แบ่งงานเป็น stage ใช้ resource ไม่ชนกัน
  • ทำหลายคำสั่งพร้อมกัน → เร็วขึ้น แต่เกิด hazard
  • เปรียบ: ซักผ้า → อบ → รีด → เก็บ
  • Stage: IF → ID → EX → MEM → WB
  • ลำดับที่อาจารย์ย้ำ: Fetch → Decode → Execute → Write back
  • ⚠ ใช้ได้ทั้ง RISC (ARM) และ CISC (Intel) ไม่ใช่เฉพาะ RISC
