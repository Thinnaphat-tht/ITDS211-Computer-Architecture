Ch04Associative · Write Policy★ ถูกถาม

  • Set-associative: index เดียวเก็บได้หลายชุด
  • 2-way เก็บ 2 · 4-way เก็บ 4 · 8-way เก็บ 8
  • แค่เพิ่มที่เก็บต่อ index → โอกาส hit มากขึ้น
  • ★ Fully associative = miss น้อยสุด (hit มากสุด)
  • Miss rate: 1-way 10.3% · 2-way 8.6% · 4-way 8.3% · 8-way 8.1%
  • ดีขึ้นแต่ได้น้อยลงเรื่อยๆ
Write policyความหมาย
Write-throughเขียนลง cache แล้วส่ง CPU เลย
Write-backส่ง CPU ก่อน แล้วค่อยอัปเดต cache ทีหลัง
Write-allocateอีกทางเลือกของ write-through
ปัจจุบัน memory เร็วขึ้น กลไกการเขียนหมดความสำคัญ เน้นยัดโค้ดที่ใช้บ่อยเข้า L1 · แต่ต้องรู้ชื่อทั้ง 3 คำ
