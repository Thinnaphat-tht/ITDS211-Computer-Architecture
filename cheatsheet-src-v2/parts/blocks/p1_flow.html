Ch01–02CPU ทำงานยังไง · Register★ ดู flow ให้ออก

  • CPU = Control Unit + ALU + Registers + Bus
  • วงจร: Fetch → Decode → Execute → Store (Write back)
  • PC เก็บ ตำแหน่งคำสั่งถัดไป
  • IR เก็บคำสั่งที่ fetch มาแล้ว
  • Status/Flag เก็บ overflow, negative
  • MAR = address ใน Memory
  • MBR = data ที่เข้า/ออก Memory
  • IOAR = address ของ I/O
  • IOBR = data ที่รับจาก I/O
★ ตัวอย่างอาจารย์ (assignment)
  • PC = 300 → Mem[300] = 1940 → โหลดเข้า IR
  • 1940: 4 บิตบน = opcode (0001 = Load AC จาก Memory)
  • ที่เหลือ 940 = address ของข้อมูล
  • Mem[940] = 0003 → AC = 0003
