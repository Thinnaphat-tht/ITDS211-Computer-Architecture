Ch02Bus · Arbitration★ Daisy chain = priority

  • Address bus บอกตำแหน่งใน Memory
  • Data bus ส่งข้อมูล
  • Control bus สัญญาณเปิด/ปิด/เลือกอุปกรณ์
  • Point-to-point: แยกทุกหน้าที่ ง่ายสุดแต่ เปลืองเส้น
  • Multipoint: ประหยัด (ไฮเวย์ + ซอย) แต่ต้องมี โปรโตคอลควบคุม
Arbitrationหลักการ
1 Daisy chainตาม priority (CPU > Memory > I/O)
นิยมสุด ใช้ถึงวันนี้
ข้อเสีย: priority ต่ำแทบไม่ได้ใช้ bus
2 Centralized parallelทุกอุปกรณ์ต่อตรงเข้า ตัวควบคุมกลาง
3 Distributed self-detectionไม่มีตัวกลาง ตัดสินกันเอง เช็กเองว่ามีใครส่งอยู่ไหม
4 Distributed + collision detectionเหมือน 3 + ตรวจจับการชน ถ้าชน ส่งซ้ำ
  • ★ ตัวเลือกว่าอุปกรณ์ไหนได้ใช้ bus = Bus Arbitrator
  • ⚠ ไม่ใช่ Control Unit และ ไม่ใช่ control line
  • การ์ดจอเสียบเมนบอร์ดผ่าน PCIe
  • InfiniBand = I/O ความเร็วสูงสุด ใช้กับ GPU ↔ memory
