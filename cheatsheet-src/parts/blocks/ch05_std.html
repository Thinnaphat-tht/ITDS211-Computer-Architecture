Ch05I/O Standards★ assignment: USB vs SCSI · Thunderbolt · InfiniBand

มาตรฐานจุดสำคัญ (ตามสไลด์)
USB1.0: Low 1.5 / Full 12 Mbps · 2.0: 480 Mbps · 3.0/3.1 Gen1: 5 Gbps (SuperSpeed) · 3.1 Gen2: 10 Gbps · 3.2 Gen2×2: 20 Gbps · root host controller · tree (hierarchical) · hot-plug
SCSIshared bus 16/32 อุปกรณ์ · ส่งแบบ parallel (bus 16 → 32 บิต) · 5 Mbps (SCSI-1) → 160 Mbps (Ultra3) · เสียความนิยมให้ USB/FireWire · ยังใช้กับ enterprise mass storage
FireWireIEEE 1394 · ทางเลือกแทน SCSI · daisy chain ≤ 63 อุปกรณ์/port · hot plug · auto config · ไม่ต้อง terminator
ThunderboltIntel+Apple · ≤ 10 Gbps ต่อทิศ · ≤ 10 W · รวม data+video+audio+power ในสายเดียว
InfiniBandhigh-end server · switch-based fabric ต่อได้ราว 64,000 อุปกรณ์ · storage area network · ★ อาจารย์: ใช้กับ GPU ↔ memory ที่ต้องการความเร็วสูงสุด
PCI Expresshigh-speed bus หลายชนิดอุปกรณ์ · ★ การ์ดจอ (GPU) ต่อเมนบอร์ดผ่าน PCIe (ไม่ใช่ USB/FireWire/Thunderbolt)
SATA / Eth / Wi-FiSATA = disk ≤ 6 Gbps · Ethernet ≤ 100 Gbps (switch-based) · Wi-Fi 802.11ac ≤ 3.2 Gbps
