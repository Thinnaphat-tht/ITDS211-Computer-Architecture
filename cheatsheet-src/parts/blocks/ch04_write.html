Ch04Write Policy★ ควรรู้นิยามสามคำ

  • Write-through: เขียนทั้ง cache และ memory ทุกครั้ง (consistent แต่ช้า: CPI = 1 + 0.1×100 = 11) → ใช้ write buffer (CPU ไปต่อ · stall เมื่อ buffer เต็ม)
  • Write-back: เขียนเฉพาะ cache + ตั้ง dirty bit · เขียนกลับ memory เมื่อ block ถูกแทนที่
  • Write allocation (เมื่อ write miss): allocate = ดึง block มาก่อนเขียน · write around = ไม่ดึง เขียนลง memory ตรง ๆ · write-back มัก fetch block
  • อาจารย์: เมื่อก่อนมีงานวิจัยแข่งกลไกเขียน แต่ปัจจุบัน transistor เล็ก (2–4 nm) เร็วขึ้น ความต่างน้อย → เน้นให้โค้ดที่ใช้บ่อยอยู่ L1 ให้มากที่สุด
