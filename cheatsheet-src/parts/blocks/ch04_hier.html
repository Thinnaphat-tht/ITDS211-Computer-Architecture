Magnetic tape
ช้าสุด · ถูกสุด · จุมากสุด (off-line)
  • Inboard memory = Register + Cache + Main memory · Outboard storage = disk/optical · Off-line = tape (big data center) · Cache: L1 ชิด CPU ก้อนเดียวกัน, L2/L3 อยู่นอก core · บน = เร็ว/แพง/จุน้อย · ล่าง = ช้า/ถูก/จุมาก · SRAM เร็วกว่า DRAM ~100 เท่า (transistor on-off ไม่กี่ตัว) แต่แพงกว่า · DRAM = ประจุใน capacitor ต้อง refresh ตลอด ช้ากว่า ถูกกว่า
  • RAM = ชั่วคราว (volatile) · ROM = ถาวร ปิดไฟข้อมูลยังอยู่ · Flash (nonvolatile; เร็วกว่า disk 100–1000×; $/GB ระหว่าง disk กับ DRAM; สึกหรอ → wear leveling): NOR random access ใช้เก็บคำสั่งใน embedded · NAND หนาแน่น/ถูก เขียนทีละ block (USB, media)
  • Locality: Temporal = ของที่เพิ่งใช้ มักถูกใช้ซ้ำเร็ว ๆ (loop) · Spatial = ของใกล้ ๆ ที่เพิ่งใช้ มักถูกใช้ตาม (array, คำสั่งต่อเนื่อง)
