Arbitrationหลักการ
Daisy chainส่งสิทธิ์ตาม priority สูง→ต่ำ (CPU สูงสุด) นิยมสุด · ข้อเสีย: priority ต่ำ (I/O) แทบไม่ได้ใช้ bus
Centralized parallelทุกอุปกรณ์ต่อตรงเข้า arbitration circuit กลาง
Distributed self-detectionไม่มีตัวกลาง อุปกรณ์ตัดสินกันเอง เช็กว่ามีใครส่งอยู่ไหม
Distributed collision-detectionส่งได้เลย ถ้าข้อมูลชนเสียหาย → ส่งซ้ำ (retransmit)
⚠ ตัวที่เลือกว่าใครได้ใช้ bus = Bus Arbitrator / arbitration circuit (ไม่ใช่ Control Unit · ไม่ใช่ control line)
  • Hardware (วงจรเฉพาะงาน เร็ว แต่ตายตัว) vs Software (instruction codes + interpreter ยืดหยุ่น = ร้านตามสั่ง)
