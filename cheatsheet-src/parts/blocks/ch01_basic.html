Ch01พื้นฐานBasic Computer Components

  • Architecture = สิ่งที่ programmer เห็น (ISA, addressing mode, data type) “อะไร” · Organization = ตัว implement (cache, pipeline, bus width, clock) “อย่างไร”
  • องค์ประกอบ: CPU (Control Unit · ALU · Registers · interconnect), Memory, Storage, I/O, Motherboard, PSU, GPU
  • ★ Machine cycle: Fetch → Decode → Execute → Store (Write back) — อาจารย์ย้ำเรื่อง ลำดับ
  • PC = address ของคำสั่งถัดไป (+ หลัง fetch) · IR = คำสั่งที่ fetch มา · Status/Flag = Overflow, Negative
  • Multi-core = hardware จริง ทำงานขนาน · Multi-thread = แบ่งงานเสมือนบน core (Hyper-Threading / SMT)
  • RISC = Reduced Instruction Set (Decoder ถอดตรง) · CISC = Complex (microprogram mPC/mPM) · pipeline ใช้ได้ทั้งคู่
  • Cloud: SaaS ให้ซอฟต์แวร์ · PaaS ให้แพลตฟอร์มรัน app · IaaS ให้ VM/ฮาร์ดแวร์ผ่าน API
  • 8 Great Ideas: Moore's Law · Abstraction · Common case fast · Parallelism · Pipelining · Prediction · Hierarchy of memories · Dependability via redundancy
