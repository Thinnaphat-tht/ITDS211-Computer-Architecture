0Striping ไม่ redundant · NI/O สูงมาก ง่าย ไม่มี parity · แต่ ดิสก์เดียวเสีย = ข้อมูลทั้ง array หาย · video/image editing
1Mirroring (copy ซ้ำ) · 2Nredundant 100% ไม่ต้อง rebuild · read ได้จากดิสก์ใดก็ได้ · แต่ overhead สูงสุด · accounting/payroll
2Parallel access + Hamming code (ECC) · N+m (m∝log N)transfer สูงมาก · แต่ ECC disk เยอะ ไม่คุ้ม · ไม่มีใช้เชิงพาณิชย์
3Parallel access, parity ระดับ bit/byte · ดิสก์ parity เดียว · N+1transfer สูงสุด · ดิสก์เสียแทบไม่กระทบ · แต่ transaction rate ≈ ดิสก์เดียว · video streaming
4Independent access, parity ระดับ block · parity disk แยก · N+1read สูง · แต่ write penalty (อ่าน 2 เขียน 2) parity disk = bottleneck · ไม่มีใช้
5block parity กระจาย (distributed) ทุกดิสก์ · N+1read สูงสุด ไม่มี bottleneck · เขียนช้ากว่า rebuild ยาก · file/database/web server · versatile สุด
6block parity 2 ชุด (dual distributed) · N+2ทนดิสก์เสีย 2 ตัวพร้อมกัน availability สูงสุด · controller ซับซ้อน write penalty สูง · mission critical
