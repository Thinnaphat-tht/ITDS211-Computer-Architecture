Ch04Virtual Memory · Coherenceท้ายบท (สไลด์)

  • Virtual memory = ใช้ main memory เป็น “cache” ของ disk · แต่ละโปรแกรมมี virtual address space ส่วนตัว (ป้องกันกัน) · CPU+OS แปล virtual → physical · block = page (เช่น 4 KB) · miss = page fault (ช้ามาก OS จัดการ)
  • Page table (index ด้วย virtual page number; page table register ใน CPU) เก็บ physical page number + status (referenced, dirty) · วางแบบ fully associative · LRU ประมาณด้วย reference bit · เขียนแบบ write-back เท่านั้น (dirty bit)
  • TLB (Translation Look-aside Buffer) = cache ของ page table · 16–512 PTE · hit 0.5–1 cycle · miss 10–100 cycle · miss rate 0.01–1%
  • Cache coherence (หลาย core): snooping (ทุก cache ดัก bus; invalidate ก่อนเขียน) vs directory-based · Virtual machine: host/VMM จำลอง guest OS (VMware, VM/370)
