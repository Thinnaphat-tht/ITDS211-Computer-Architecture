Ch04Cache: Hit/Miss · Direct-Mapped★ อาจารย์ “เน้นเรื่อง Cache”

  • Cache = หน่วยความจำเร็วคั่นกลาง CPU↔Main memory เก็บข้อมูลที่ใช้บ่อย/ซ้ำ · Block (line) = หน่วยที่ copy · Hit = เจอใน cache · Miss = ไม่เจอ → ดึง block จาก main memory มาใส่ cache แล้วส่ง CPU (เวลา = miss penalty) · Hit ratio = hits/accesses · Miss ratio = 1 − hit ratio
Direct-mapped: Cache index = (Block address) modulo (#Blocks in cache) → ใช้ บิตล่าง เป็น index
Address = [ Tag | Index | Block offset ]   offset = log₂(bytes/block) · index = log₂(#blocks) · tag = ที่เหลือ
  • เช็ก hit/miss: ดู Index → เทียบ Tag → ดู Valid bit (V) = 1 (เริ่มต้น cache ว่าง V=0) · ข้อเสีย: หลาย address ชิงช่องเดียวกัน (แย่งกัน/conflict)

  • Block ใหญ่ขึ้น: miss rate ลด (spatial locality) แต่ cache ขนาดคงที่ → blocks น้อยลง แย่งกัน miss rate กลับเพิ่ม · miss penalty สูงขึ้น · ใหญ่ ≠ ดีเสมอ ⚠
