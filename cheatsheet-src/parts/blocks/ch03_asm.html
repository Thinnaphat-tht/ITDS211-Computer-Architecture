add rd,rs1,rs2rd = rs1 + rs2 (sub = ลบ) · รูปทั่วไป ADD A,B,C = A ← B + C (2 source + 1 dest)
addi rd,rs1,immrd = rs1 + ค่าคงที่ · addi x22,x22,4 → x22 ← x22 + 4
ld/lw rd,off(rs1)LOAD Memory → Register (ld 64 บิต · lw 32 · lb/lh sign-ext · lbu/lhu/lwu zero-ext)
sd/sw rs2,off(rs1)STORE Register → Memory (sd 64 · sw 32 · sh 16 · sb 8 เก็บบิตขวาสุด)
and or xor (+i)bitwise · and = mask (เก็บบางบิต ที่เหลือ 0) · or = บังคับบิตเป็น 1 · xor กับ 1…1 = NOT
slli / srli rd,rs1,ishift ซ้าย i บิต = ×2i (เติม 0) · shift ขวา = ÷2i (unsigned)
beq / bne rs1,rs2,Lกระโดดไป L ถ้า rs1 = rs2 / ≠ rs2 (ไม่ใช่ → ทำคำสั่งถัดไป)
blt / bge rs1,rs2,Lถ้า rs1 < rs2 / rs1 ≥ rs2 (signed) · bltu bgeu = unsigned (−1 < +1 แต่ unsigned 4,294,967,295 > 1)
jal rd,L · jalrกระโดด + เก็บ address ถัดไปใน rd (เรียก procedure: jal x1,L) · return = jalr x0,0(x1)
lui rd,imm20ใส่ imm 20 บิตที่ rd[31:12] เคลียร์ [11:0] → สร้างค่าคงที่ 32 บิตคู่ addi
