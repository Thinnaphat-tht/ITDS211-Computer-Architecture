Ch04AMAT · CPU time กับ memory stall

AMAT = Hit time + Miss rate × Miss penalty
CPU time = (execution cycles + memory stall cycles) × cycle time
Stall cycles = (Mem accesses/Program) × Miss rate × Penalty = (Instr/Program) × (Misses/Instr) × Penalty
ตย. AMAT clock 1 ns, hit 1 cycle, penalty 20 cycles, miss 5% → 1 + 0.05×20 = 2 ns  ·  ตย. CPI base CPI 2, I-miss 2%, D-miss 4%, load/store 36%, penalty 100 → 2 + 0.02×100 + 0.36×0.04×100 = 2 + 2 + 1.44 = 5.44 → ideal เร็วกว่า 5.44/2 = 2.72 เท่า
  • Multilevel: L1 เน้น hit time ต่ำ · L2 เน้น miss rate ต่ำ · block L1 < block L2 · ตย. CPI = 1 + 0.02×20 + 0.005×400 = 3.4 (เทียบ 9 ถ้ามี L1 อย่างเดียว → 2.6 เท่า)
