  • External device 3 กลุ่ม: Human readable (จอ/คีย์บอร์ด) · Machine readable (disk/sensor) · Communication · ประกอบด้วย Control logic + Buffer + Transducer (แปลง digital↔analog) · สัญญาณ Control / Status / Data
  • I/O module 5 หน้าที่: ① Control & timing ② Processor communication (ถอดรหัส command, ส่งข้อมูล, รายงาน status, จำ address) ③ Device communication ④ Data buffering (memory เร็ว I/O ช้า → balance speed) ⑤ Error detection
  • I/O command 4: Control (สั่งให้ทำ) · Test (ดู status) · Read (ดึงข้อมูลจากอุปกรณ์เข้า buffer) · Write (เอาข้อมูลจาก data bus ส่งอุปกรณ์) · สายของ module: Address · Control · Data
  • I/O addressing: Memory-mapped = address space เดียวกับ memory ใช้คำสั่ง memory ได้หมด ไม่มีคำสั่ง I/O พิเศษ · Isolated = แยก space ต้องมี I/O/memory select line + คำสั่ง I/O เฉพาะ (จำกัด)
Flow (สไลด์) Programmed: Issue Read → Read status → Check (ไม่พร้อม = วนกลับ) → Read word → Write ลง memory → Done? (ยัง = วนอีก) · Interrupt-driven: Issue Read → ทำงานอื่น → รอ interrupt จึง Read status/word · DMA: Issue Read-block ให้ DMA → ทำงานอื่นทั้งหมด → DMA interrupt เมื่อเสร็จ
