Ch04ท้ายบท: Dependability · Virtual Memoryอยู่ในสไลด์ (ติวยังไม่ได้พูด)

  • Dependability: Reliability = MTTF · ซ่อม = MTTR · MTBF = MTTF + MTTR · Availability = MTTF/(MTTF+MTTR) (เพิ่มโดย ↑MTTF หรือ ↓MTTR)
  • Hamming distance (จำนวนบิตที่ต่าง): 2 = ตรวจ error 1 บิต (parity) · 3 = แก้ 1 บิต + ตรวจ 2 บิต · parity bit อยู่ตำแหน่งกำลังของ 2 · SEC/DEC (distance 4) · ECC DRAM = 8 บิต ต่อทุก 64 บิต
  • Virtual memory: main memory = “cache” ของ disk · virtual → physical · block = page (≈4 KB) · miss = page fault (ช้ามาก, OS จัดการ) · page table (index ด้วย virtual page no.; มี physical page no. + referenced/dirty bit) · fully associative · write-back เท่านั้น · TLB = cache ของ page table (16–512 PTE, hit 0.5–1 cycle, miss rate 0.01–1%)
  • Cache coherence (หลาย core): snooping (ดัก bus; invalidate ก่อนเขียน) vs directory-based · Virtual machine: host/VMM จำลอง guest OS
