Ch01อื่น ๆ ในสไลด์Below your program · Classes · Patterns

  • Below your program: Application software (เขียนด้วย high-level) → System software (Compiler แปล HLL → machine code · OS จัดการ I/O, memory/storage, scheduling) → Hardware (processor, memory, I/O controller) · High-level → Compiler → Assembly → Assembler → Binary
  • Supercomputer = คำนวณวิทย์/วิศวกรรมระดับสูงสุด ส่วนแบ่งตลาดเล็ก · Embedded = ซ่อนเป็นส่วนประกอบในระบบ (หลายพันล้านชิ้น/ปี) ผูกกับสภาพแวดล้อม มี real-time ทำหลายกิจกรรมพร้อมกัน ข้อจำกัด power/performance/cost เข้ม · ARM Cortex-M = ตอบ interrupt เร็วและ deterministic กินไฟต่ำ
  • Parallelism ในแอป: DLP (data-level) · TLP (task-level) · ในสถาปัตยกรรม: ILP · Vector/GPU · Thread-level · Request-level
  • System pattern: Monolithic (ระบบเดียว) · Client-server (แยกฝั่งขอ/ฝั่งให้บริการ) · Distributed (กระจายหลายเครื่อง) · Microservices (บริการย่อย deploy แยกได้)
