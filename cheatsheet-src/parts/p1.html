Ch01Performance · CPU time · CPI★ ข้อคำนวณ

Performance = 1 / Execution time
X เร็วกว่า Y n เท่า: PerfX/PerfY = TimeY/TimeX = n  (ตย. A 10 s, B 15 s → 15/10 = 1.5)
CPU time = Clock cycles × Cycle time = Clock cycles / Clock rate
Clock cycles = IC × CPI ⇒ CPU time = IC × CPI × Cycle time = IC × CPI / Clock rate
  • Clock rate = 1/period (250 ps = 0.25 ns · 4 GHz = 4×10⁹ Hz) · Elapsed time (รวม I/O, OS, idle) ≠ CPU time (user + system)
  • IC ← โปรแกรม/ISA/compiler · CPI ← hardware · CPI เฉลี่ย ← instruction mix = Σ(CPIi × ICi/IC)
ตย. CPI (สไลด์) ISA เดียวกัน A: 250 ps, CPI 2.0 · B: 500 ps, CPI 1.2 → A = I×2.0×250 = 500I ps · B = I×1.2×500 = 600I ps → A เร็วกว่า 1.2 เท่า (IC ตัดทิ้ง ถ้าไม่รู้ค่าติดตัวแปรไว้)
ตย. Clock (สไลด์) A: 2 GHz, 10 s · B ต้องเสร็จใน 6 s แต่ใช้ cycles มากกว่า 1.2 เท่า → Clock rateB = 1.2×(10×2×10⁹)/6 = 4 GHz
⚠ “เร็วกว่า” = ใช้เวลาน้อยกว่า · อ่านโจทย์ดี ๆ ว่าใครหารใคร (บัญญัติไตรยางศ์)

Ch02Interrupt★ ขั้นตอน “จำไว้เลย”

  • Interrupt = ขัดจังหวะการทำงานแบบ sequence ของ CPU · ชนิด: Program (overflow, หาร 0, illegal instr) · Timer · I/O (เสร็จ/ขอบริการ/error) · Hardware failure (ไฟดับ, parity) · Hardware vs Software interrupt (system call)
  1. เซฟ context (PC/PSW, register, ตัวแปร) ไว้ก่อน
  2. ดู Interrupt Vector table หา ISR address (ใครเป็นคนเรียก)
  3. ใส่ address นั้นใน PC → กระโดดไปทำ ISR (Interrupt Service Routine)
  4. เสร็จ → Restore ค่าที่เซฟ แล้วกลับไปทำงานเดิมต่อ
  • Sequential: ทำทีละตัวตามลำดับ (เกิด→ทำ→กลับ→เกิดอีก) · Nested: ระหว่าง ISR ของ X มี Y ซ้อน → เซฟสถานะ X → ทำ Y → คืน X → ทำ X ต่อ → return · ซ้อนได้กี่ชั้นขึ้นกับ CPU (จำนวนชุด register ที่เก็บ context)
  • มักปิด interrupt ระหว่างทำ ISR (maskable ปิดได้ · nonmaskable ต้องทำ) · interrupt ต้องรอ instruction cycle จบ
