  • Multi-core = duplicate core จริง ๆ ทำงานขนาน (≠ แบ่ง task บน resource เดียว/VM) · Multithreading = replicate register+PC สลับ thread เร็ว: Fine-grain (สลับทุก cycle) · Coarse-grain (สลับเมื่อ stall ยาว เช่น L2 miss; ไม่ซ่อน stall สั้น) · SMT (คำสั่งจากหลาย thread รันพร้อมกันบน function unit ที่ว่าง; Intel Hyper-Threading 2 thread)
  • Vector processor: function unit pipelined ลึก · vector register (RISC-V: v0–v31, 32×64-element) · ลดการ fetch คำสั่ง · เหมาะ data-parallel: multiply–accumulate (digital filter, ภาพ, linear algebra — ตย. DAXPY: Y = a×X + Y) · vector = ความกว้างปรับได้ + stride ≠ multimedia SIMD (SSE/MMX 128 บิต กว้างคงที่)
  • Shared memory (SMP: hardware ให้ address space เดียว, sync ด้วย lock; UMA/NUMA): ✓ ไม่ต้อง duplicate/ไม่ต้อง sync ข้อมูล ✗ ทุก core รุมเข้า memory ตัวเดียว · Distributed memory (แต่ละตัวมี memory เอง = cluster, message passing): ✗ sync/update ยาก ✓ scalable/ถูก/availability สูง · cluster = คอมพิวเตอร์อิสระ+OS ของตัวเอง ต่อด้วย Ethernet (loosely coupled) · Grid computing เช่น SETI@home
  • ปัญหา parallel programming: Partitioning · Coordination · Communications overhead · SPMD = Single Program Multiple Data · topology: Bus · Ring · 2D Mesh · N-cube · Fully connected · benchmark: Linpack · SPECrate · SPLASH · NAS · PARSEC · performance model: GFLOPs, arithmetic intensity = FLOPs/byte (Roofline)

Ch08GPU★ อาจารย์ปิดคลาสด้วยหัวข้อนี้

  • หลักการ = SIMD: คำสั่งเดียว (บวก/ลบ) ทำกับข้อมูลจำนวนมากพร้อมกัน (ตย. ลบ background ภาพ — pixel = array/vector) · highly multithreaded (สลับ thread ซ่อน memory latency) · พึ่ง multi-level cache น้อยกว่า CPU · graphics memory กว้าง/bandwidth สูง · heterogeneous: CPU ทำ sequential, GPU ทำ parallel · API: CUDA, OpenGL, DirectX
  • Nvidia Fermi: vector-based · SIMD processor 16 lanes · SIMD instruction ทำกับ 32 element รันบน 16-wide ใน 2 cycle · Tesla: multiprocessor (หลาย compute unit ทำร่วมกัน) · DGX = train AI model (แพง) · รันโมเดลแล้ว ใช้การ์ดจอปกติเสียบ PCIe ใน PC ได้
  • Multicore SIMD vs GPU: SIMD processor 4–8 vs 8–16 · SIMD lane/processor 2–4 vs 8–16 · SIMD thread/processor 2–4 vs 16–32 · cache ใหญ่สุด 8 MB vs 0.75 MB · main memory 8–256 GB vs 4–6 GB
