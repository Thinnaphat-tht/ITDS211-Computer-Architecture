Ch06Hard Disk★ storage ออกไม่เยอะ เน้น “หลักการอ่าน/เขียน”

  • เขียน: จ่ายกระแสเข้าหัวเขียน (ขดลวด) → เกิดสนามแม่เหล็ก → จัดทิศอนุภาคบนผิว platter ซ้าย/ขวา = 0/1 · อ่าน: ขดลวดหัวอ่านเหนี่ยวนำดูทิศ (inductive write / magnetoresistive read) · platter เคลือบวัสดุแม่เหล็ก · 1 head ต่อ 1 surface · หัวแบบ Winchester ลอยด้วยแรงลม (aerodynamic)
  • Platter → Track (วงแหวนหนึ่งวง) → Sector (ส่วนย่อยของ track ⚠ ไม่ใช่กลุ่มของ track) · Cylinder = track ตำแหน่งเดียวกันทุก platter · มี gap ระหว่าง track/sector · sector ≈ 512 B (ใหม่ 4096) + ID + ECC
  • Constant angular velocity (หั่นเค้ก sector ขนาดไม่เท่ากัน) vs Multiple-zone recording (density/sector ใกล้เคียงกัน ดีกว่า · ปัจจุบันใช้แบบนี้)
  • Seek time = เลื่อนหัวไปถึง track · Rotational delay = รอต้น sector มาถึงหัว · Access time = seek + rotational delay · transfer time = อ่านข้อมูลเมื่ออยู่ถูกตำแหน่ง
Disk access = queuing + seek + rotational latency + transfer + controller overhead
Rotational latency เฉลี่ย = ½ รอบ = 0.5 / (rpm/60)
ตย. สไลด์ sector 512 B, 15,000 rpm, seek เฉลี่ย 4 ms, transfer 100 MB/s, controller 0.2 ms, disk ว่าง → 4 + 2 + 0.005 + 0.2 = 6.2 ms (rotational = 0.5/(15000/60) = 2 ms · ถ้า seek จริง 1 ms → 3.2 ms)
